# Как опубликовать новый сайт вместо Tilda

Важно: **в Tilda нельзя «загрузить» этот React-проект как файлы**. Tilda — конструктор со своим хостингом. Новый сайт нужно разместить на **отдельном хостинге** и **перенаправить ваш домен** с Tilda на новый хостинг.

## Что вы получаете после сборки

Команда:

```bash
npm run build
```

Создаёт папку **`dist/`** — это готовый статический сайт (HTML, JS, CSS, картинки). Её и нужно загрузить на хостинг.

## Рекомендуемые хостинги (бесплатный тариф)

| Сервис | Плюсы |
|--------|--------|
| [Netlify](https://www.netlify.com) | Простая загрузка `dist`, SSL, свой домен |
| [Vercel](https://vercel.com) | То же для Vite/React |
| [Cloudflare Pages](https://pages.cloudflare.com) | Быстро, бесплатный SSL |

### Netlify (пошагово)

1. Зарегистрируйтесь на netlify.com.
2. **Sites → Add new site → Deploy manually** — перетащите папку `dist`.
3. **Domain settings → Add custom domain** — укажите ваш домен (например `artiada.ru` или поддомен).
4. Netlify покажет DNS-записи (обычно `A` или `CNAME`). Их нужно внести у регистратора домена.

В проекте уже есть `public/_redirects` для корректной работы `/admin` и других маршрутов.

## Переход с Tilda на свой домен

1. **Соберите сайт локально:** `npm run build`.
2. **Опубликуйте `dist`** на Netlify/Vercel.
3. В **панели Tilda** (Настройки сайта → Домен) **отвяжите домен** от Tilda или удалите старые DNS-записи Tilda.
4. В **панели регистратора домена** (Reg.ru, nic.ru и т.д.) укажите DNS хостинга из шага 2.
5. Подождите 1–24 часа (распространение DNS).

Адрес сайта останется прежним (ваш домен), но содержимое будет уже с нового хостинга.

Поддомен Tilda (`artiada.tilda.ws`) после переноса можно оставить или отключить в настройках Tilda.

## Заявки на почту 07baa@mail.ru

Форма отправляет письма через **FormSubmit.co** на `07baa@mail.ru`.

При **первой** отправке с сайта на почту придёт письмо **«Activate Form»** — обязательно нажмите ссылку подтверждения, иначе заявки не будут приходить.

Проверка: откройте сайт → «Принять участие» → отправьте тестовую заявку.

## Обновление сайта после правок

1. Редактируете контент (админка, фото, новости).
2. `npm run build`
3. Снова загружаете `dist` на хостинг (или подключаете Git — Netlify соберёт сам).

## Админ-панель на опубликованном сайте

Редактор галереи и новостей (`/admin`) работает **только при запущенном локальном сервере**:

```bash
npm run dev:full
```

Откройте http://localhost:5173/admin — пароль по умолчанию `artiada2025`.

После изменений: `npm run build` → загрузить `dist` на хостинг.

Для редактирования прямо на сервере без компьютера понадобится отдельная настройка (CMS с базой данных) — при необходимости можно обсудить отдельно.
