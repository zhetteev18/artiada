# Как добавить и заменить фото на сайте

Все изображения лежат в папке **`public/images/`**.  
Код менять не нужно — только положить файл в нужную папку и перезапустить сайт.

## Быстрая шпаргалка

| Раздел сайта | Папка | Имя файла |
|--------------|-------|-----------|
| Фон главной | `public/images/hero/` | `hero.jpg` |
| Тарбоков | `public/images/people/` | `tarbokov.jpg` |
| Бетуганов | `public/images/people/` | `betuaganov.jpg` |
| Документы (4 шт.) | `public/images/cofounders/` | `01.jpg`, `02.jpg`, `03.jpg`, `04.jpg` |
| Новость | `public/images/news/` | `{slug}.jpg` — slug из news.ts |
| Галерея | `public/images/gallery/` | любые имена |
| «Золотой микрофон» | `public/images/videos/` | `01.jpg` … `04.jpg` |

## Шаги

1. Скопируйте фото в нужную папку (можно заменить существующий файл с тем же именем).
2. В терминале в папке проекта:

```bash
npm run media
```

или

```bash
npm run dev
```

3. Обновите страницу в браузере (Ctrl+Shift+R).

## Форматы

`.jpg`, `.jpeg`, `.png`, `.webp`

Рекомендуемый размер для фона: от 1920×1080 px.  
Для карточек новостей: около 1200×675 px.

## Только текст (без кода)

- Новости: `src/data/news.ts`
- Подписи к документам: `src/data/cofounders-docs.ts`
- Остальной текст: `src/data/content.ts`
