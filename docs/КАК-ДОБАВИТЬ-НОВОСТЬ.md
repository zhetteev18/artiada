# Как добавить новость

## Текст

Файл: `src/data/news.ts` — новый объект **в начало** массива `news`.

Поле `slug` — латиница без пробелов (например `moya-novost`).

## Фото

Положите файл в:

```
public/images/news/moya-novost.jpg
```

Имя файла = `slug` + `.jpg` (или `.png`, `.webp`).

## Обновить сайт

```bash
npm run dev
```

Фото подхватится автоматически. Подробнее: `public/images/README.md`
