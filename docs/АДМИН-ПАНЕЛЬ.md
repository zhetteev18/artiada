# Админ-панель: галерея и новости

## Запуск

```bash
npm run dev:full
```

- Сайт: http://localhost:5173  
- Админка: http://localhost:5173/admin  
- Пароль по умолчанию: **artiada2025** (смените через `ADMIN_TOKEN` в `.env`)

## Галерея

- Загрузка: кнопка «Загрузить фото» — можно выбрать несколько файлов.
- Удаление: кнопка под каждым превью.
- Файлы сохраняются в `public/images/gallery/`.

## Новости

- Список всех новостей, кнопки «Редактировать» / «Удалить».
- «Добавить новость» — заголовок, дата, slug, текст, фото.
- **Несколько фото:** в редакторе новости — «Загрузить фото (можно несколько)».
  - Файлы попадают в `public/images/news/ВАШ-SLUG/`
  - Старый вариант одного файла `public/images/news/slug.jpg` тоже поддерживается.

После сохранения новостей обновите страницу главного сайта (F5).

## Публикация изменений на интернет

```bash
npm run build
```

Загрузите папку `dist` на хостинг (см. `docs/ПУБЛИКАЦИЯ.md`).

## Без админки (вручную)

- Галерея: положить файлы в `public/images/gallery/` → `npm run media`
- Новости: править `src/data/news.ts` → `npm run news:export` → `npm run dev`
- Фото новости: `public/images/news/slug/` или `slug.jpg`
